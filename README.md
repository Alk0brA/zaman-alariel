# 📺 زمن الأريل

منصة تفاعلية لذكريات جيل الثمانينات والتسعينات: الأريل والتلفزيون القديم، برامج الأطفال، الكورة في الحارة، الشبسات وجوائزها، الفيديو والكستات، والجمعات العائلية.

## المميزات
- **تذكر؟** أسئلة تفتح السوالف وتشجع الناس يشاركون.
- إضافة ذكرى بالكتابة أو **بالصوت** (على Chrome وAndroid)، مع صورة وسنة وتصنيف ومدينة.
- زر **📺 أتذكرها**، وترتيب الذكريات من الأكثر تذكّراً.
- **خط زمني** للسنين والعقود.
- لعبة **خمّن البرنامج**.
- **جوائز الشبس**: ١٢ جائزة تنفتح مع المشاركة.
- **📴 نهاية الإرسال**: شاشة الألوان بعد منتصف الليل.

## التشغيل على Render (الطريقة الحالية)
الموقع شغال على Render: خادم Node (`server.js`) مع قاعدة Postgres، والذكريات والصور مشتركة بين الكل بدون أي إعداد.
- أمر البناء: `npm install`، وأمر التشغيل: `npm start`
- متغير البيئة المطلوب: `DATABASE_URL`

## التشغيل على GitHub Pages (بديل)
1. في المستودع: **Settings → Pages**.
2. في **Source** اختر **Deploy from a branch**، وبعدها `main` و`/ (root)`، واضغط **Save**.
3. بعد دقيقة أو دقيقتين يصير الموقع على:
   `https://alk0bra.github.io/zaman-alariel/`

إذا ما ربطت الموقع بـ Supabase، يشتغل في **وضع تجريبي**: كل شخص يشوف ذكرياته على جهازه بس.

## ربط قاعدة بيانات مشتركة (Supabase — مجاني)
1. أنشئ مشروع في [supabase.com](https://supabase.com).
2. افتح **SQL Editor**، والصق محتوى `setup.sql` كامل، واضغط **Run**.
3. من **Project Settings → API** انسخ:
   - **Project URL**
   - مفتاح **anon / publishable**
4. حطهم في `config.js`، وارفع التعديل للمستودع.

> لا تحط مفتاح `service_role` في الموقع أبداً.

## الإشراف
- كل شخص يقدر يحذف ذكرياته من نفس الجهاز اللي أضافها منه.
- عشان تحذف أي ذكرى غير لائقة: **Supabase → Table Editor → memories**، واحذف الصف.
