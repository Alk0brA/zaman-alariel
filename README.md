# 📺 زمن الأريل

منصة تفاعلية لجيل الثمانينات والتسعينات: ذكريات، وألعاب بروح الأتاري وكمبيوتر العائلة، ودواوين دردشة، ولوحة تحكم لصاحب المنصة.

## الأقسام
- **الذكريات:** أسئلة «تذكر؟»، ونشر ذكرى بالنص أو الصوت مع صورة، وزر «أتذكرها»، وخط زمني للسنين.
- **صالة الألعاب:** ست ألعاب بتصاميم أصلية، ولكل لعبة لوحة أبطال:
  مغامرة الحارة، قنص الطيور، الطوب المتساقط، الثعبان، تكسير الطوب، حرب الفضاء.
- **الدواوين:** غرف دردشة. كل مستخدم يختار يظهر باسمه الحقيقي أو باسم مستعار.
- **خمّن وجوائز:** مسابقة عن برامج زمان، و١٥ جائزة تنفتح مع المشاركة.
- **التسجيل:** بعد مدة تحددها من لوحة التحكم، تطلب المنصة من الزائر الاسم والبريد، والجوال اختياري. فيه موافقة على سياسة الخصوصية، وموافقة منفصلة على الرسائل التسويقية.
- **نهاية الإرسال:** شاشة الألوان بعد منتصف الليل.

## لوحة التحكم — `/admin`
- **نظرة عامة:** المستخدمون، والزوار، والذكريات، والرسائل، ومرات اللعب، ورسم بياني لآخر ١٤ يوم.
- **المستخدمون:** بحث، وتصدير CSV يفتح في Excel (للكل أو للموافقين على التسويق بس)، وإيقاف أو حذف أي حساب.
- **الذكريات:** مراجعة وحذف.
- **الدواوين:** إضافة غرف وتعديلها وقفلها، ومراقبة الرسائل وحذفها.
- **الألعاب:** تفعيل أو إيقاف كل لعبة، ولوحة الأبطال، وتصفير النتائج.
- **الإعدادات:** اسم المنصة، وشريط الإعلان، ووقت طلب التسجيل، والتسجيل الإجباري، وتشغيل الأقسام، وأسئلة «تذكر؟».

## التشغيل
- خادم Node بدون أي إطار عمل (`server.js`)، والمكتبة الوحيدة `pg`.
- قاعدة البيانات Postgres. الجداول تنشأ تلقائياً أول ما يشتغل الخادم.
- متغيرات البيئة:
  | المتغير | الوظيفة |
  |---|---|
  | `DATABASE_URL` | رابط Postgres |
  | `ADMIN_PASSWORD` | كلمة مرور لوحة التحكم |
  | `SESSION_SECRET` | اختياري — مفتاح توقيع جلسات الإدارة |
- أمر البناء `npm install`، وأمر التشغيل `npm start`.
